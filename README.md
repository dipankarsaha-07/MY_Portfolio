## About

I'm Dipankar Saha. This portfolio presents an overview of my background, projects, and contact details. The website is intentionally simple and responsive so it works well on desktop and mobile.

## What you'll find here

- A personal landing page (index.html) with an introduction and links to projects.

- Interactive behavior (menu, animations, contact form handling) in `script.js`.
- My photo (`Dipankar.jpg`) and resume (PDF).

## Technologies

- HTML5
- CSS3

## Run locally

1. Clone the repository:

   git clone https://github.com/dipankarsaha-07/MY_Portfolio.git

2. Open the project directory and launch the site by opening `index.html` in your browser, or run a simple HTTP server:

   - Python 3: `python -m http.server 8000` and visit `http://localhost:8000`
